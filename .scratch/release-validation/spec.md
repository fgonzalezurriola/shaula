# Release validation

Migrate the remaining v0.1.9 release validation from the roadmap into explicit,
independently verifiable architecture and desktop-environment gates.

Source: `docs/roadmap.md` and the verified release state in `CONTEXT.md`.

## Scope

- Validate optimized x86_64 and native/QEMU AArch64 release archives.
- Validate graphical portal capture and shortcut journeys on GNOME and KDE.
- Record concrete evidence without broadening the supported runtime contract.
